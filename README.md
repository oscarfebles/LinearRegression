In this little project you will learn how to stablish a Linear Regression model using four libraries: numpy, pandas, sklearn and mathplotlib.
It's based on a "imaginary problem" in which i asked GPT for randoms Salaries and Weights of 50 people. 
We try to verify if there's any relation between the salary and the weigth. 
In other words, this tries to verify if the weight depends on the salary but it could be done the other way.
